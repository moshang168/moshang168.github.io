## VS Code为什么是现在最火的编辑器

微软的VS Code之所以成为开发者首选，核心就是靠插件生态：原本只是个基础编辑器，装上合适的插件后可以变成全能开发工具，写代码、看文档、远程开发、甚至画图都能完成。但很多新手装了一堆没用的插件反而让编辑器变卡，我整理了真正日常开发每天都会用到的插件清单，拒绝花里胡哨。

---

## 一、基础必备插件（所有开发者都需要）

### 1. Chinese (Simplified) Language Pack
微软官方简体中文语言包，装完直接把整个VS Code界面改成中文，对新手非常友好。

### 2. Prettier - Code formatter
代码格式化神器，支持JavaScript/TypeScript/CSS/HTML/Markdown几乎所有常见格式，保存文件时自动按统一规则格式化，再也不用手动调整缩进。

配置方法：在设置里打开 `Editor: Format On Save`，每次保存自动格式化。

### 3. GitLens
Git功能增强插件，每一行代码后面都会显示最近是谁、什么时间、哪个提交改的，看历史代码非常方便，还能直接可视化对比不同版本的差异。

### 4. Error Lens
把代码里的报错信息直接显示在错误行后面，不用把鼠标悬停上去才能看错误原因，调试效率翻倍。

---

## 二、代码效率类插件

### 1. Code Spell Checker
代码拼写检查，自动检查变量名、注释里的英文拼写错误，避免出现拼写错误的尴尬。

### 2. Bracket Pair Colorization
括号配对自动高亮，嵌套层级深的时候不同层级的括号会显示不同颜色，一眼就能看清括号匹配关系，不会写多写少括号。

### 3. Auto Rename Tag
修改HTML标签的时候，开始标签和结束标签会同步自动重命名，不用手动改两次。

### 4. Path Intellisense
自动补全文件路径，写导入文件的时候不用手动敲长路径，自动提示目录下的文件。

---

## 三、大模型AI辅助编程

### 1. GitHub Copilot
现在最火的AI代码补全插件，写注释的时候自动生成对应代码，函数名写一半就自动补全整个函数，日常写代码效率提升至少50%。

### 2. Continue
开源免费的AI编程助手，可以接入你自己本地部署的Ollama大模型，完全免费无次数限制，隐私数据不会上传。

---

## 四、远程与容器开发

### 1. Remote - SSH
通过SSH直接连接远程服务器，在本地VS Code里写远程服务器上的代码，和本地开发体验完全一致，不用频繁传文件。

### 2. Dev Containers
直接在Docker容器里开发，开发环境和本地电脑完全隔离，不会出现"我电脑上能跑你电脑跑不了"的环境问题。

---

## 五、实用增强小工具

### 1. Image Preview
写Markdown或者HTML的时候，鼠标悬停在图片路径上就能直接预览图片，不用打开图片查看器。

### 2. Markdown All in One
Markdown编辑增强，支持快捷键生成目录、自动列表、实时预览，写文档和博客的必备插件。

### 3. Todo Tree
自动收集项目里所有的TODO、FIXME注释，侧边栏直接展示所有待办项，写代码时标记的待办不会漏掉。

### 4. Peacock
给不同项目的VS Code窗口设置不同的主题色，同时打开多个项目的时候一眼就能区分窗口，不会改串项目代码。

---

## 避坑提醒

1. 不要装太多重复功能的插件：比如多个代码补全、多个格式化插件，反而会冲突拖慢速度
2. 不用的插件及时禁用：插件装多了VS Code启动会变慢，只保留每天真正会用到的
3. 不要装主题美化类的花里胡哨插件：写代码的时候越简洁越不容易分心，把时间留给代码本身
