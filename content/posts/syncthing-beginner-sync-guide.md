## 同步不是备份，先弄清区别

Syncthing 是一个开源的连续文件同步工具，可以让你授权的设备之间交换文件变化。它不是传统意义上的云硬盘：通常由你的设备彼此同步，也可能借助发现或中继服务建立连接；共享文件的设备都应是你信任并管理的。

最重要的一点：删除和修改也会同步。如果你把某个文件夹同步到两台电脑后误删文件，删除可能很快传播到另一台。因此，正式同步前先读懂文件夹类型、版本控制和备份策略。

## 下载与第一次启动

打开 [Syncthing 官方下载页](https://syncthing.net/downloads/)，选择你的操作系统，再按 [官方入门指南](https://docs.syncthing.net/intro/getting-started.html)完成设置。Windows 用户下载对应压缩包后解压并启动程序；若使用社区封装的图形启动器，仍应从官方文档链接进入可信项目。

首次启动后，管理界面通常在本机浏览器打开。管理页面地址只供本机访问时，不要把它改成无密码的公网管理入口。先在一台电脑上创建一个测试目录，例如 Documents 下的 SyncTest，只放几份可删除的测试文件。

## 配对第二台设备

1. 在两台设备上都安装并启动 Syncthing。
2. 在设备一的页面查看本机设备 ID，或使用二维码/分享按钮。
3. 在设备二选择“添加远程设备”，粘贴设备 ID。
4. 给设备起容易辨认的名字，例如“家里台式机”。
5. 在设备一收到请求后核对设备名称和 ID，再接受连接。

设备 ID 用来识别对端，不要把它当成普通公开用户名随意贴在陌生网站。只添加你认识、确实属于自己的设备。

## 共享第一个文件夹

在设备一添加文件夹，选择测试目录并设置一个简短的文件夹标签。勾选刚才配对的设备作为共享对象。设备二会收到文件夹共享请求；只有你确认并选择本机保存位置后，文件才会同步过来。

两台设备上的文件夹路径可以不同。例如电脑 A 共享 D 盘里的 Notes 文件夹，电脑 B 保存到用户文档目录下的 Notes。路径不同不代表内容不同，它们由文件夹 ID 关联。

首次同步文件很多时，设备会扫描并传输，CPU、磁盘和网络可能短时变忙。等状态显示已同步后，在一台电脑新建 hello.txt，再去另一台确认它出现。

## 选择合适的文件夹类型

双向同步适合两台设备都可能编辑的文件夹；发送端只读或只发送模式则适合资料发布。对刚入门的人，先用双向同步处理普通文件，不要把系统文件夹、浏览器配置目录或正在运行的数据库放进去。

重要资料建议开启文件夹版本控制（若当前平台和版本提供），并在另一块硬盘或独立备份介质上定期备份。版本控制能帮助恢复旧文件，但不能替代异地备份或离线备份。

## 设备在同一个 Wi-Fi 下可以，异地不行

先在两台设备都保持 Syncthing 运行，检查设备页是否显示已连接。若能在同一局域网同步、外网不行，可能是路由器、防火墙或公司网络限制连接。不要为了“让它连上”就把管理界面端口直接暴露到公网；先阅读官方网络与防火墙说明。

## 常见问题

**设备已连接但文件夹没同步：**确认双方都接受了共享、两端的文件夹 ID 一致、保存路径存在且有写权限。

**空间突然占满：**检查是否把 Downloads 或照片总目录整个共享了；先停用该文件夹，清点数据，再决定要不要继续。

**误删除扩散：**暂停相关设备同步，避免继续写入；检查回收站或文件版本目录，同时从独立备份恢复。不要以为另一台同步设备永远保留“删除前”的副本。

**移动设备支持如何选：**桌面端优先按官方页面安装。移动系统上的客户端来源和维护状态会变化，使用前核对应用发布者、权限和最近更新情况。
