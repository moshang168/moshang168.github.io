## 先认识 OpenClash 的几个部件

OpenClash 是运行在 OpenWrt 系列路由系统上的 LuCI 管理界面，负责管理代理核心、配置文件和流量规则。可以把它想成“路由器上的交通调度台”：设备的流量进入路由器后，规则决定直连、代理或拒绝。

本文只讲基础部署和规则配置。你需要自己拥有合法可用的服务配置；请遵守所在地法律、网络服务条款和内容版权要求。不要把订阅地址、账号密码或含有密钥的 YAML 文件贴到公开论坛。

![家庭路由器将不同网络流量按规则分流的插图](/images/covers/router-openclash.jpg)

## 安装前先做三项检查

### 1. 记录固件信息

在路由器“状态/概览”页面记下系统名称、版本、设备架构和可用存储空间。OpenWrt 24.10 及更早版本通常使用 opkg；25.12 及之后的系统切换到 apk。此外，插件包还要匹配防火墙后端（nftables 或 iptables）和系统架构，不能只看文件名里有“OpenWrt”就安装。

### 2. 备份并准备回退方式

先导出系统配置备份，确认自己能通过有线连接重新打开路由管理页。安装前不要改动 WAN、LAN 地址和 DHCP 等基础设置。建议在网络空闲时操作，避免更新中断。

### 3. 只用项目官方发布页

下载入口：[OpenClash 官方 GitHub Releases](https://github.com/vernesong/OpenClash/releases)。先阅读当前版本说明和依赖清单，按自己的固件包管理器与防火墙类型选择对应文件。不要安装论坛转发的“万能包”，也不要把未知脚本直接复制进 SSH 执行。

## 安装与第一次启动

在 LuCI 的“系统 → 软件”页面更新软件列表，再按官方发布说明安装匹配的 OpenClash 包和依赖；不同固件菜单名称可能略有不同。如果官方步骤要求 SSH 命令，先确认命令中的 apk 或 opkg 与本机一致，再执行。

安装完成后刷新 LuCI，找到“服务 → OpenClash”。先检查“运行状态”和核心管理页面；如果缺少核心，使用面板提供的核心管理功能或按项目说明下载与固件架构匹配的核心。核心不是 LuCI 插件本身，二者版本和架构都需要匹配。

## 导入配置并从最小范围开始

在配置管理页导入你自己的配置文件或订阅。导入前先确认来源可信，文件中不要有过期账号或公开分享的密钥。第一次启动建议保持规则模式，不要一开始就选全局代理；规则模式便于把不需要代理的本地服务保持直连。

按顺序检查：

1. 配置页面能看到节点或规则列表。
2. 核心检查没有格式错误。
3. 选择规则模式，指定当前配置为运行配置。
4. 启动 OpenClash，观察日志是否显示核心正常运行。
5. 先用一台测试设备访问常用网页，再逐步验证其他设备。

如果界面有 DNS 劫持选项，先阅读本机现有 DNS 配置，避免多个插件同时争用 53 端口。一次只改一个选项，出错就回退到刚才的状态。

## 常见故障怎么查

**插件页面不出现：**刷新浏览器、重新登录 LuCI，确认依赖安装成功及插件包与固件版本匹配。

**核心无法启动：**查看日志中的架构、缺少动态库、权限或配置解析错误；先修复明确报错，不要连续更换多个版本。

**路由器能上网，终端不能：**暂时停止 OpenClash，确认基础路由和 DHCP 正常；再检查 DNS 监听端口、DNS 劫持和防火墙规则，恢复时一次只启用一个功能。

**只有部分网站失败：**检查当前规则是否命中、配置是否更新、系统时间是否正确。先在面板里查规则命中记录，不要直接关闭防火墙。

**断网无法管理：**用有线设备访问 LAN 管理地址；如果仍无法恢复，按之前备份和固件提供的恢复流程操作。
