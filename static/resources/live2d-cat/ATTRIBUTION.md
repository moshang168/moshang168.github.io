# Live2D cat model attribution

This folder includes the runtime files for **Tororo**, a cat sample model created and modeled by Live2D Inc.

- Official model page: https://www.live2d.com/en/learn/sample/tororo-hijiki/
- Sample data terms: https://www.live2d.com/download/sample-data/
- The sample's `ReadMe.txt` says general users and small-scale businesses may use it commercially after agreeing to the Free Material License Agreement and the sample data terms.

The blog uses the Tororo runtime model files only. The original orange 3D cat shown in the supplied video is not included in this Live2D model.
